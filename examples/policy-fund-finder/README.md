# 정책자금 길잡이

소상공인·중소기업이 받을 수 있는 정책자금의 **종류 · 신청 조건 · 필요 서류**를 한 화면에서 확인하고, **작성 양식과 작성예시**를 내려받는 정적 웹 도구입니다. 빌드 과정과 외부 라이브러리가 없습니다.

## 실행

```bash
cd examples/policy-fund-finder
python3 -m http.server 8080   # 브라우저에서 http://localhost:8080
```

`index.html`을 브라우저로 직접 열어도 동작합니다. 서류 다운로드는 파일 경로로 연결되어 있어 폴더 전체를 함께 두어야 합니다.

## 화면

| 탭 | 내용 |
|----|------|
| 내게 맞는 자금 | 업종·상시근로자 수·업력·신용·수출·매출 감소 등을 입력하면 28개 자금을 "입력 기준 충족 / 확인 필요 / 해당 없음"으로 나누고 이유를 보여줍니다 |
| 전체 자금 비교 | 기관·방식·용도·키워드로 거르는 한도·금리·기간 비교표 |
| 서류 · 양식 | 양식 5종(빈 양식 + 작성예시)과 서류별 발급처 |
| 접수 일정 · 문의 | 소진공 접수 현황(확인일 표시), 문의처, 불법 브로커 주의 |

자금을 누르면 대상·조건, 신청 절차, **서류 체크리스트**가 열립니다. 체크 상태는 브라우저에 저장되고 CSV로 내려받을 수 있습니다.

## 자료 기준

| 구분 | 근거 |
|------|------|
| 소진공 (소상공인) | 중기부 공고 제2025-656호, 3차 변경 제2026-448호(2026.07.10). 앞선 변경 제2026-140호·제2026-271호를 통합한 최신본 |
| 중진공 (중소기업) | 중기부 공고 제2025-649호, 변경공고 제2026-464호(2026.07.28) |
| 접수 현황 · 신청 절차 | 소상공인정책자금 사이트(ols.semas.or.kr) 첫 화면과 이용안내서 v3.9, 2026-10-13 확인 |

최초 공고와 변경본을 대조해 다음을 반영했습니다.

- 소진공 소공인특화자금의 "유망형(직접대출)"은 3차 변경본에 없어 제외했습니다.
- 홈플러스 피해 소상공인 전용 긴급경영안정자금(3차 변경 신설)을 추가했습니다.
- 중진공 지원규모와 성장공유형 대출 방식 추가를 반영했습니다.

## 서류 구분

자금별 제출서류의 정적인 공식 목록은 공개되어 있지 않습니다. 소진공은 신청 화면에서 자금·우대사항별 "필수" 서류를 보여주고, 중진공은 "상담 이후 별도 안내"로 정합니다. 그래서 서류마다 출처 구분을 붙였습니다.

- **공고·안내 명시**: 공고문이나 이용안내서에 적힌 서류와 절차
- **일반 요구**: 흔히 요구되지만 자금·창구에 따라 달라질 수 있는 서류. 신청 화면의 "필수" 표시가 최종 기준

## 알려진 한계

- 정책자금 기준금리는 분기마다 바뀌므로 수치를 넣지 않고 "기준금리 ± x%p"로 표기합니다.
- 중진공 창업기반지원자금은 공고 요약표(시설 −0.6%p)와 상세 항목(−0.3%p)의 표기가 다릅니다. 화면에 그 사실을 적어 두었습니다.
- 자격 진단은 입력값 기반의 1차 점검입니다. 예외 규정을 모두 반영하지 못하며 심사 결과를 보장하지 않습니다.
- 양식은 공식 서식이 아닌 준비용입니다. 작성예시의 상호·이름·금액은 모두 가상 값입니다.

## 데이터 갱신

1. `data/funds.js`의 자금·서류·접수 현황을 고칩니다. 각 자금에는 출처(`src`)가 있습니다.
2. 자격 규칙은 `data/eligibility.js`의 `RULES`에서 자금 id별로 고칩니다.
3. 양식은 `tools/build_forms.py`를 고친 뒤 `python3 tools/build_forms.py`로 `forms/`를 다시 만듭니다 (`python-docx`, `openpyxl` 필요).
4. `node tests/examples/policy-fund-finder.test.js`로 데이터 연결과 규칙을 검증합니다.

공고는 변경이 잦으므로 접수 현황(`SCHEDULE`)과 확인일(`AS_OF`)을 갱신할 때마다 공식 사이트와 다시 대조하세요.

## 구성

```text
index.html, style.css, app.js     화면
data/funds.js                     자금·서류·양식·일정 데이터 (출처 포함)
data/eligibility.js               자격 진단 규칙
forms/                            내려받는 양식 (docx, xlsx)
tools/build_forms.py              양식 생성 스크립트
```
