# 정책자금 한눈에 보기

소상공인·중소기업 정책자금의 종류, 신청 조건, 필요 서류를 한 화면에서 보고, 내게 맞는 자금을 진단하고, 사업계획서 초안과 서류 양식을 내려받는 정적 웹 페이지입니다. 서버와 외부 라이브러리가 없고, 빌드 없이 `index.html`을 브라우저로 열면 동작합니다.

## 화면 구성

| 탭 | 하는 일 |
| --- | --- |
| 자금 목록 | 소진공·중진공 자금 32개를 검색하고 기관·대상·자금군·자료 기준으로 거릅니다. 자금을 고르면 조건, 절차, 서류 체크리스트, 원문 링크를 보여 줍니다. |
| 내게 맞는 자금 | 업종, 상시근로자 수, 업력, 신용·수출·매출, 해당 사항을 입력하면 자금별로 충족, 확인 필요, 해당 없음을 판정하고 이유를 보여 줍니다. |
| 사업계획서 초안 | 입력한 사실만으로 소진공용(영업현황·경력·자금집행계획) 또는 중진공용 초안을 만듭니다. 빈 항목은 【작성 필요】로 남기고, 절별 복사와 Word(.docx) 내려받기를 지원합니다. |
| 서류·양식 | 사업계획서, 자금집행계획표(상환 시뮬레이터 포함), 위임장, 자가진단표의 빈 양식과 작성예시를 내려받고, 필요 서류를 한눈에 봅니다. |
| 일정·문의 | 소진공 접수 현황(확인일 표시), 문의처, 공식 사이트, 불법 브로커 주의를 보여 줍니다. |

화면의 양식과 초안은 공식 서식이 아니며 개인이 정리한 신청 준비용 자료입니다. 이 문구는 해당 화면과 바닥글에 표시됩니다.

## 데이터와 병합 규칙

두 자료를 합쳐 자금 32개를 만듭니다. 갱신은 CSV를 교체한 뒤 `node apps/policy-fund/tools/build-data.js`를 실행합니다.

- **겹치는 자금은 CSV가 이깁니다.** 이름, 대상, 한도, 금리, 기간, 방식, 서류, 변경 메모는 CSV 값을 그대로 씁니다(소진공 제2026-576호, 중진공 제2026-574호, 2026.10.1 기준). 이전 정리본에서는 서류 체크리스트, 진단 규칙, 요건 상세, 용도, 참고 사항만 가져옵니다.
- **이전 정리본에만 있는 중진공 자금 8개**는 `source: "legacy"`, 자료 기준 "이전 공고 기준"으로 덧붙이고 화면에 "이전 공고 기준" 표시를 둡니다. 최신 공고와 대조하지 못했습니다.
- **값이 엇갈리면 어느 쪽도 고르지 않고** "확인 필요"로 표시하고 두 값을 모두 보여 줍니다. 현재 하나입니다. 창업기반지원자금(일반)의 시설자금 금리가 공고 요약표에는 −0.6%p, 상세 항목에는 −0.3%p로 적혀 있습니다(CSV는 상세 항목과 같음).
- **옛 규모 수치는 옮기지 않습니다.** 청년고용연계자금의 운용 규모(1,500억원 내외)는 최신 변경공고에서 조정되어 싣지 않았습니다.
- 위 세 가지(값 엇갈림, 이전 공고만, 싣지 않음)는 `funds.json`의 `reconciliation`과 자금 목록 탭의 "자료 대조 메모"에 목록으로 남습니다.
- 자금별 한도의 숫자(`limitWon`)는 초안의 한도 점검에만 쓰며, CSV 한도 문구와 맞춰 두었습니다.

## 서식 파일

`forms/`의 파일은 `python3 apps/policy-fund/tools/build_forms.py`로 만듭니다(python-docx, openpyxl 필요). 작성예시의 상호·이름·금액은 모두 가상 데이터이고, 항목 구성은 소진공 사이트 이용안내(영업현황·경력·자금집행계획)와 중진공 기업평가 항목을 따릅니다.

## 내려받기 동작

- 일반 웹 페이지(저장소를 정적 호스팅하거나 `file://`로 열 때): 평범한 다운로드 링크로 동작합니다. 사업계획서 .docx와 체크리스트 CSV는 브라우저에서 만들어 저장합니다.
- Claude Artifact 안: 뷰어가 페이지의 다운로드 링크와 스크립트 저장을 막으므로 뷰어의 `downloads` 기능으로 저장합니다. 저장할 때마다 확인창이 뜨고, 취소하면 "저장을 취소했습니다."라고 표시합니다. 양식 파일은 페이지에 base64로 넣어 둔 것을 씁니다(`window.PF_FORM_FILES`).
- 저장 기능이 없는 뷰어에서는 서류·양식 탭에 안내 문구를 보여 주고 버튼은 "이 화면에서는 파일을 저장할 수 없습니다"라고 알립니다. 초안은 "전체 텍스트 복사"로 가져갈 수 있습니다.

## 글꼴

글꼴은 항상 Pretendard입니다. `fonts/pretendard-subset.woff2`는 Pretendard Variable 1.3.9(SIL OFL 1.1, `fonts/LICENSE-Pretendard.txt`)에서 굵기 400~700, 기본 라틴, KS X 1001 한글 2,350자와 화면에 쓰이는 글자만 남긴 서브셋입니다. 목록에 없는 글자는 시스템 한글 글꼴로 대체되므로 화면 문구에 새 글자를 넣었다면 다시 만드세요. npm `pretendard` 패키지의 `PretendardVariable.woff2`를 fontTools로 `varLib.instancer`(굵기 제한) → 파일로 저장 → `subset`(글자 제한, `flavor=woff2`) 순서로 처리합니다. 기본 서브셋에 없던 ±, ①②③, 「」, 【】는 추가해 두었습니다.

## 한 장짜리 HTML로 게시하기

`node apps/policy-fund/tools/build-artifact.js <출력파일.html>`로 CSS, 글꼴, 데이터, 스크립트 전부(`index.html`에 적힌 순서대로), 양식 파일을 안에 넣은 단일 HTML을 만듭니다. 이 파일을 Claude Artifact로 같은 URL에 다시 올리면(Artifact 도구에 같은 파일 경로 또는 `url` 지정) 데이터가 갱신될 때마다 같은 주소에서 새 버전을 볼 수 있습니다. 파일 저장 기능을 쓰려면 게시할 때 `capabilities: {downloads: true}`를 함께 지정합니다. 공개 호스팅(GitHub Pages 등)은 아직 정하지 않았습니다.

## 알려진 한계

- 소진공 필요 서류의 전체 목록은 공고문에 없어(소진공 신청안내자료 따름) "공고·안내 기준 서류"에는 "전체 목록 미확인"으로 표시합니다. 체크리스트의 "일반 요구" 서류는 흔히 요구되는 항목이며 창구에 따라 달라질 수 있습니다.
- 소진공·중진공 모두 신청서를 온라인으로 작성·제출하므로 공식 서식 파일 링크는 없습니다. 확인되면 `funds.json`의 `forms`(`label`, `url`)에 채우면 버튼이 생깁니다.
- 자격 진단, 서류 체크리스트, 초안은 이전 정리본(제2026-448호·464호) 기준의 1차 점검이며, 최신 공고에서 바뀐 요건은 "변경" 표시와 자금 상세를 함께 확인해야 합니다. 심사 결과를 보장하지 않습니다.
- 접수 현황은 2026-10-13 확인 값이라 날짜가 지나면 화면에 며칠 전 자료인지 표시합니다. 접수 기간이 끝난 항목에는 "기간 지남"이 붙습니다.
- 중진공 밸류체인안정화(동반성장 네트워크론, 매출채권팩토링)의 한도·금리·기간은 공고문에 없어 "미확인"으로 표시합니다.
- 금리는 분기별 기준금리에 가산금리를 더하는 구조라 실제 %는 기관 공지를 확인해야 합니다.
- 중진공 자금은 소상공인 제외가 원칙이라 대상이 "중소기업"으로 분류됩니다(공고에 소상공인 포함 가능이라고 명시된 자금만 둘 다).
- Word(.docx)와 한컴오피스에서 직접 열어 본 것은 아닙니다. LibreOffice와 python-docx로는 열림을 확인했습니다.
